# Hotel Management — Flet client

Кроссплатформенное клиентское приложение на [Flet](https://flet.dev) для информационной системы управления гостиницей.

## Возможности

- Регистрация / вход / выход (JWT)
- Личный кабинет: редактирование профиля
- Каталог номеров с фильтрами (категория, цена, вместимость, доступность по датам)
- Просмотр детальной карточки номера и удобств
- Бронирование: выбор дат, гостей, дополнительных услуг — расчёт стоимости в реальном времени
- Список своих бронирований с возможностью отмены и скачивания PDF-бланка
- Админ-панель (для admin/manager): пользователи, номера, услуги, бронирования, отчёты, журнал аудита
- Современный дизайн: собственная палитра, тёмная и светлая темы, аккуратная типографика
- Полная поддержка кириллицы и форматов RU (даты, валюта)

## Стек

- Python 3.11+ (рекомендуется 3.13)
- Flet 0.25+ — UI и навигация
- httpx — асинхронный HTTP-клиент
- pydantic — валидация

## Запуск

```bash
cd client
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env  # отредактируйте HOTEL_API_URL при необходимости
python -m hotel_client
```

По умолчанию клиент подключается к `http://77.221.151.85` (production-сервер курсового проекта).

## Запуск в браузере

```bash
python -m hotel_client --web
```

Откроется на `http://localhost:8550`.

## Структура

```
hotel_client/
├── __main__.py              точка входа
├── api.py                   ApiClient: JWT, httpx, обработка ошибок
├── theme.py                 дизайн-токены: палитра, типографика, радиусы
├── state.py                 глобальное состояние сессии (текущий пользователь, тема, тосты)
├── components/
│   ├── buttons.py           кастомные кнопки (Primary/Ghost/Outline)
│   ├── inputs.py            поля ввода с валидацией и подписями
│   ├── cards.py             карточки номеров и бронирований
│   ├── nav.py               боковая навигация
│   └── toasts.py            всплывающие уведомления
└── views/
    ├── login.py / register.py
    ├── home.py              каталог номеров
    ├── room_detail.py
    ├── booking_create.py
    ├── my_bookings.py
    ├── profile.py
    ├── admin_dashboard.py
    ├── admin_users.py
    ├── admin_rooms.py
    ├── admin_bookings.py
    ├── admin_audit.py
    └── reports.py
```
