# HotelMS — Веб-клиент

Веб-интерфейс системы управления гостиницей, реализованный как одностраничное приложение (SPA) на чистом HTML/CSS/JavaScript без фреймворков.

## Структура проекта

```
web/
├── index.html          # Главная HTML-страница (точка входа)
├── css/
│   └── style.css       # Стили приложения (CSS-переменные, адаптивный дизайн)
├── js/
│   ├── api.js          # HTTP-клиент для взаимодействия с REST API
│   └── app.js          # Логика приложения (навигация, рендеринг страниц)
└── README.md           # Этот файл
```

## Возможности

### Для всех пользователей
- **Авторизация** — вход по email/паролю с JWT-токеном
- **Регистрация** — создание нового аккаунта с профилем гостя
- **Каталог номеров** — просмотр номеров с фильтрами по категории, статусу, этажу
- **Бронирование** — создание бронирования с выбором дат, количества гостей и доп. услуг
- **Мои бронирования** — просмотр истории, детали, скачивание PDF-бланка
- **Профиль** — редактирование ФИО, телефона, паспортных данных, смена пароля

### Для администраторов и менеджеров
- **Управление бронированиями** — подтверждение, заселение, выселение, отмена
- **Управление пользователями** — смена ролей, блокировка/разблокировка
- **Отчёты** — доход по категориям номеров, загруженность гостиницы
- **Журнал аудита** — просмотр всех операций с данными (INSERT/UPDATE/DELETE)

## Технические характеристики

### Архитектура
- **SPA (Single Page Application)** — навигация без перезагрузки страницы
- **Vanilla JS** — без зависимостей от фреймворков (React, Vue, Angular)
- **REST API** — взаимодействие с бэкендом через HTTP-запросы
- **JWT** — аутентификация через Bearer-токен в заголовке Authorization

### Дизайн
- **CSS-переменные** — централизованное управление цветами, отступами, тенями
- **Адаптивная вёрстка** — корректное отображение на мобильных устройствах (breakpoint 768px)
- **Шрифт Inter** — через Google Fonts
- **Иконки Font Awesome 6.5** — через CDN
- **Цветовая схема**:
  - Основной: `#1565C0` (синий)
  - Акцентный: `#FF8F00` (янтарный)
  - Фон: `#F5F5F5` (светло-серый)
  - Текст: `#212121` (тёмно-серый)

### Компоненты UI
- Навигационная панель с информацией о пользователе
- Карточки номеров с градиентными заголовками
- Модальные окна для бронирования и просмотра деталей
- Уведомления (toast) с автоскрытием
- Таблицы с горизонтальной прокруткой
- Фильтры с выпадающими списками
- Бейджи статусов (цветовое кодирование)
- Вкладки для навигации в админ-панели

## Запуск

### Вариант 1: Через FastAPI (рекомендуется)

Веб-клиент автоматически обслуживается FastAPI-сервером:

```bash
cd server
source .venv/bin/activate
WEB_DIR=/path/to/web uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000 в браузере.

### Вариант 2: Отдельный HTTP-сервер

```bash
cd web
python3 -m http.server 3000
```

Откройте http://localhost:3000 в браузере. В `js/api.js` необходимо указать `API_BASE` на адрес API-сервера.

## API-клиент (api.js)

Класс `HotelAPI` предоставляет методы для всех эндпоинтов:

| Метод | Описание |
|-------|----------|
| `login(email, password)` | Авторизация |
| `register(data)` | Регистрация |
| `getProfile()` | Получение профиля |
| `updateProfile(data)` | Обновление профиля |
| `changePassword(data)` | Смена пароля |
| `getRooms(params)` | Список номеров с фильтрами |
| `getRoom(id)` | Детали номера |
| `getCategories()` | Категории номеров |
| `createBooking(data)` | Создание бронирования |
| `getMyBookings()` | Мои бронирования |
| `getAllBookings()` | Все бронирования (admin) |
| `cancelBooking(id)` | Отмена бронирования |
| `updateBookingStatus(id, status)` | Смена статуса (admin) |
| `getServices()` | Список услуг |
| `getBookingPdf(id)` | Скачивание PDF-бланка |
| `getUsers()` | Список пользователей (admin) |
| `setUserRole(userId, role)` | Смена роли (admin) |
| `blockUser(userId, blocked)` | Блокировка (admin) |
| `getRevenue(params)` | Отчёт по доходам (admin) |
| `getOccupancy()` | Загруженность (admin) |
| `getAudit(params)` | Журнал аудита (admin) |

## Безопасность

- JWT-токен хранится в `localStorage` и автоматически добавляется к каждому запросу
- При ответе 401 (Unauthorized) происходит автоматический выход из системы
- Интерфейс адаптируется к роли пользователя — элементы управления скрыты для неавторизованных ролей
- Все операции валидируются на стороне сервера
