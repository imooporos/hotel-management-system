# Hotel Management System — Client

Десктопный клиент на базе Flet для системы управления гостиницей.

## Технологии

- **Flet** — кроссплатформенный UI-фреймворк (Desktop / Web / Mobile)
- **httpx** — асинхронный HTTP-клиент
- **Python 3.11+**

## Структура

```
client/
├── hotel_client/
│   ├── __init__.py
│   ├── main.py              # Точка входа приложения
│   ├── api_client.py         # HTTP-клиент для работы с API
│   ├── theme.py              # Тема и стили интерфейса
│   ├── components/
│   │   └── __init__.py
│   └── views/
│       ├── __init__.py
│       ├── login_view.py      # Экран входа
│       ├── register_view.py   # Экран регистрации
│       ├── rooms_view.py      # Каталог номеров
│       ├── booking_view.py    # Форма бронирования
│       ├── profile_view.py    # Личный кабинет
│       ├── my_bookings_view.py # Мои бронирования
│       └── admin_view.py      # Панель управления
└── pyproject.toml             # Зависимости проекта
```

## Установка и запуск

```bash
# Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Установить зависимости
pip install -e .

# Запустить клиент (подключение к развёрнутому серверу)
HOTEL_API_URL=http://77.221.151.85:8000 python -m hotel_client.main
```

## Экраны приложения

### Для всех пользователей (guest, manager, admin)
- **Вход** — авторизация по email/паролю
- **Регистрация** — создание нового аккаунта
- **Каталог номеров** — просмотр номеров с фильтрацией по категории и вместимости
- **Бронирование** — выбор дат, количества гостей, дополнительных услуг
- **Мои бронирования** — список бронирований, отмена, скачивание PDF
- **Профиль** — редактирование личных данных

### Для менеджеров и администраторов
- **Управление бронированиями** — подтверждение, заселение, выселение, отмена
- **Отчёты** — выручка по категориям номеров

### Только для администраторов
- **Управление пользователями** — смена ролей, блокировка аккаунтов
- **Аудит-лог** — журнал всех изменений в системе

## Дизайн

Приложение использует единую тему с цветовой палитрой:
- Основной цвет: `#1565C0` (синий)
- Акцент: `#FF8F00` (янтарный)
- Фон: `#F5F5F5` (светло-серый)
- Поверхности: `#FFFFFF` (белый)

Стилизация реализована через модуль `theme.py` с функциями для карточек, заголовков и статусных индикаторов.
