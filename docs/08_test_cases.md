## 8.2 Юнит-тесты

Файл: `server/tests/test_api.py`

### UT-01: Хэширование пароля (bcrypt)

```python
def test_password_hashing():
    """Проверяет корректность хэширования и верификации пароля."""
    password = "SecurePassword123!"
    hashed = hash_password(password)

    # Хэш не равен исходному паролю
    assert hashed != password

    # Хэш начинается с маркера bcrypt
    assert hashed.startswith("$2b$")

    # Верификация корректного пароля
    assert verify_password(password, hashed) is True

    # Верификация некорректного пароля
    assert verify_password("WrongPassword", hashed) is False
```

**Назначение**: убедиться, что функция `hash_password` создаёт валидный bcrypt-хэш, а `verify_password` корректно проверяет пароль.

**Ожидаемый результат**: все assertions проходят. Хэш начинается с `$2b$`, верификация правильного пароля возвращает True, неправильного — False.

### UT-02: Создание и декодирование JWT-токена

```python
def test_jwt_token_creation():
    """Проверяет создание JWT-токена и его декодирование."""
    payload = {"sub": "42", "email": "test@example.com", "role": "guest"}
    token = create_access_token(payload)

    # Токен — это строка
    assert isinstance(token, str)

    # Токен содержит три части (header.payload.signature)
    assert len(token.split(".")) == 3

    # Декодирование токена
    decoded = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
    assert decoded["sub"] == "42"
    assert decoded["email"] == "test@example.com"
    assert decoded["role"] == "guest"
    assert "exp" in decoded  # содержит время истечения
```

**Назначение**: убедиться, что JWT-токен создаётся с правильной структурой и содержит все необходимые поля.

**Ожидаемый результат**: токен состоит из трёх частей, при декодировании содержит переданные данные и время истечения.
