# 6. Руководство пользователя

## 6.1 Системные требования

- Python 3.11 или выше
- Подключение к интернету (для связи с сервером)
- Операционная система: Windows 10+, macOS 12+, Linux (Ubuntu 20.04+)

## 6.2 Установка клиента

```bash
# Клонировать репозиторий
git clone https://github.com/imooporos/hotel-management-system.git
cd hotel-management-system/client

# Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows

# Установить зависимости
pip install -e .

# Запустить приложение
HOTEL_API_URL=http://77.221.151.85:8000 python -m hotel_client.main
```

## 6.3 Регистрация

1. При первом запуске отображается экран входа.
2. Нажмите ссылку **«Нет аккаунта? Зарегистрироваться»**.
3. Заполните обязательные поля:
   - **Фамилия** — не менее 1 символа
   - **Имя** — не менее 1 символа
   - **Email** — действующий адрес электронной почты
   - **Пароль** — не менее 6 символов
   - **Подтверждение пароля** — должно совпадать с паролем
4. Необязательные поля: Отчество, Телефон.
5. Нажмите **«Зарегистрироваться»**.

При успешной регистрации система автоматически выполнит вход.

## 6.4 Вход в систему

1. Введите **Email** и **Пароль**.
2. Нажмите **«Войти»**.
3. При успешной авторизации откроется каталог номеров.

## 6.5 Личный кабинет (Профиль)

Перейдите в раздел **«Профиль»** через боковую панель навигации.

Доступные для редактирования поля:
- Имя, Фамилия, Отчество
- Телефон
- Серия и номер паспорта
- Дата рождения

Поля **Email** и **Роль** отображаются, но недоступны для редактирования.

Нажмите **«Сохранить»** для применения изменений.

## 6.6 Просмотр номеров

Раздел **«Номера»** отображает каталог номеров гостиницы.

### Фильтрация
- **Категория** — выпадающий список: Все / Стандарт / Комфорт / Люкс / Президентский
- **Вместимость** — минимальное количество гостей

### Карточка номера
Каждая карточка содержит:
- Номер комнаты и категорию
- Цену за сутки
- Этаж и вместимость
- Список удобств
- Статус (доступен / занят)
- Кнопку **«Забронировать»** (для доступных номеров)

## 6.7 Бронирование номера

1. Нажмите **«Забронировать»** на карточке номера.
2. Заполните форму:
   - **Дата заезда** — формат ГГГГ-ММ-ДД
   - **Дата выезда** — формат ГГГГ-ММ-ДД (должна быть позже даты заезда)
   - **Количество гостей** — не более вместимости номера
   - **Примечания** — дополнительные пожелания (необязательно)
3. Выберите дополнительные услуги (если нужны):
   - Отметьте флажки напротив услуг
   - Цена каждой услуги отображается рядом
4. Нажмите **«Забронировать»**.

Система автоматически проверит:
- Свободен ли номер на указанные даты
- Не превышает ли количество гостей вместимость
- Корректность дат

## 6.8 Мои бронирования

Раздел **«Бронирования»** отображает список ваших бронирований.

### Статусы бронирования
| Статус | Описание |
|--------|----------|
| pending | Ожидает подтверждения |
| confirmed | Подтверждено менеджером |
| checked_in | Гость заселён |
| checked_out | Гость выехал |
| cancelled | Отменено |

### Доступные действия
- **Отменить** — доступно для бронирований в статусе `pending` или `confirmed`
- **Скачать PDF** — формирование и загрузка бланка заказа

## 6.9 Скачивание бланка заказа (PDF)

1. Перейдите в раздел **«Бронирования»**.
2. Найдите нужное бронирование.
3. Нажмите кнопку **«PDF»** (иконка загрузки).
4. Файл будет сохранён в папку загрузок.

PDF-документ содержит:
- Заголовок «Гранд Отель»
- Данные гостя
- Информация о номере
- Даты проживания
- Список услуг с ценами
- Итоговую сумму

## 6.10 Выход из системы

Нажмите иконку **выхода** (🚪) в нижней части боковой панели навигации.
